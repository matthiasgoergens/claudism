## Prose for humans

<!-- llm-isms: off -->

- Before showing or publishing prose a human will read (posts, docs,
  commit messages, PR/issue text, mail), run the `llm-isms` skill: the
  mechanical checker first, then its judgement checks.
- No em-dashes, and no " -- " standing in for them.  No announced
  significance ("That's the point"), teasers, colon reveals, slogans,
  moral closers, "not X but Y" flourishes, or self-certified honesty.
- Rhetorical neatness is a tripwire: restate a pretty sentence flatly
  and publish it only if the flat version is true.
- Claim exactly what was done; keep only the precision the argument
  needs.
- Wrap plain-text mail at 72 columns; never hard-wrap GitHub comments.
- When I correct a draft, add the correction to my house style
  (`~/.config/house-style.md`) and, if it is a phrase, to
  `~/.config/llm-isms/patterns.tsv`.
